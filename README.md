# موقع عسير — حزمة HTML/CSS/JS

موقع عربي RTL مطابق لتصميم Figma (من الصفحة الرئيسية حتى 404).

## التشغيل
افتح الملف `index.html` في المتصفح، أو شغّل خادماً محلياً من هذا المجلد:

```
npx --yes serve .
```

## الملفات الأساسية
- `index.html` الصفحة الرئيسية
- `style.css` الهوية البصرية والتصميم المتجاوب
- `script.js` القائمة، الميغا منيو، البحث، التفاعل
- `assets/` الصور والأيقونات من Figma

القائمة المنسدلة «استكشف عسير» تحتوي فقط على المناطق المعتمدة:
القمم، تهامة، الساحل، الصحراء والواحات.
